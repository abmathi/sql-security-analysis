# SQL Security Analysis — Injection Testing and Remediation

An application security investigation focused on SQL injection vulnerabilities, database information disclosure, and secure query implementation.

## Investigation

**[SQL Injection Exploitation and Remediation](investigations/sql-injection-remediation/README.md)**

This investigation examines:

- UNION-based SQL injection and data extraction.
- Database schema enumeration.
- Independent testing of vulnerable Python database queries.
- Remediation using parameterized queries.
- Before-and-after security validation.

The investigation contains a technical report and four screenshots supporting its findings.

## Skills Demonstrated

- SQL injection vulnerability analysis
- Application security testing
- Database query analysis
- Python secure coding
- Parameterized query remediation
- Security validation and technical documentation

## Evidence and Scope

The testing was performed in an authorized training environment.

The investigation documents observed vulnerability behavior, remediation procedures, and the limitations of the available evidence.
